# VYRO Digital Studio

Catálogo de propuestas web para negocios de Costa Rica.

Las muestras públicas estarán en `docs/`. Son conceptos independientes, con contenido ilustrativo; no son páginas oficiales de los negocios.

Publicación: GitHub Pages, rama `main`, carpeta `/docs`.

El registro privado de prospección se conserva fuera de este repositorio público.
